# NexHub Mouse

macOS 图片与文字工具。支持 Apple 芯片（M1及更新），macOS 14 或以上。

## 第一次安装

1. [下载最新发布](https://github.com/d48gz9j28h-bit/nexhub-mouse-releases/releases/latest) 里的 **DMG 安装镜像**。
2. 打开DMG，把 **NexHub Mouse.app** 拖到 **Applications（应用程序）**。
3. 复制完成后推出安装镜像，从Mac“应用程序”打开。
4. 被macOS拦截时，先尝试打开一次，再到 **系统设置 → 隐私与安全性** 点系统提供的 **仍要打开**。当前使用开发签名，没有Developer ID和公证；公司管理的Mac可能不允许放行。
5. 在Mouse **设置 → 通用** 按需授权 **屏幕录制**、**辅助功能**，按macOS要求退出重开。
6. 到 **AI 服务** 填写自己的接口和API Key。无需登录哥哥的GitHub，真实模型调用可能计费。

**已装用户优先在原App内更新**，继续使用原目录。不要在系统 `/Applications` 和用户 `~/Applications` 各放一份。如果无系统目录写权限，可复制到 `~/Applications` 后打开。

## 日后更新

每12小时检查，也能在设置或菜单手动检查。发现可信新版时，左下设置旁出现绿色更新箭头：

**点击箭头 → 下载进度 → 校验 → 安装并重启 Mouse**。

100%表示下载完成，仍需校验后才可安装。任务处理中或未保存内容时等待；网络失败保留旧版可用，电脑不需要重启。App内置公钥验证版本信息及更新包；写GitHub的token和签名私钥均不在App或仓库内。

## 下载与验收

- 详细中文安装说明和安装包SHA256与各版DMG放在同一Release。
- 国内网络可能间歇超时，可换可访问GitHub的网络或从发布者取得同一份完整安装镜像。
- 首装包建议通过发布者既有可信渠道取得完整SHA256复核；不要关闭整机Gatekeeper。
- 另一台Mac的首次放行和跨版本权限保留仍需试点验收。当前不支持Intel Mac。

此仓库只放安装包与可信更新文件，不放产品源码、API Key或签名私钥。
