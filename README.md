# NexHub Mouse

macOS 图片与文字工具的安装包和可信更新发布。此仓库不存放产品源码、API Key 或签名私钥。

## 安装

从右侧 Releases 下载最新版 arm64 ZIP，解压放到 ~/Applications。当前支持 Apple 芯片和 macOS 14 或以上。首次尝试打开被系统拦截时，到“系统设置 → 隐私与安全性 → 仍要打开”，核对来源后确认；再授予辅助功能和屏幕录制权限。公司管理的 Mac 可能限制手动放行。

首装包建议从发布者既有可信渠道取得完整 SHA256 复核。不要关闭整机 Gatekeeper。

## 更新

App 每12小时检查一次；启动或唤醒未到期不重复请求，菜单和设置可随时手动检查。普通更新后台下载、安全退出时安装，也可立即更新。任务处理中或未保存内容时等待，断网继续使用。App 用内置公钥验证签名版本信息和更新包，日常检查无需登录 GitHub。

## 版本

完整更新源以正式 Releases 为准；draft、pre-release 不作为默认 stable 更新。缺包、坏签名或网络失败时保留当前 App。
